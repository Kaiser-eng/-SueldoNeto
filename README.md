# SueldoNeto

## Descripción

**SueldoNeto** es una calculadora de sueldo neto desarrollada en Python que permite determinar el salario final de un empleado luego de aplicar los descuentos correspondientes en República Dominicana.

El sistema considera:

- Descuento por seguridad social (TSS)
- Retención del Impuesto Sobre la Renta (ISR) según un porcentaje único
- Bonificación (si aplica)
- Otros descuentos opcionales

Este proyecto es ideal para estudiantes que deseen practicar el uso de variables, funciones, condicionales y entradas de usuario en Python.

- Python 3.13.3

## Requisitos

- No se requieren librerías externas
- Sistema operativo compatible con Python

##  Instalación y ejecución

### 1. Clona el repositorio desde GitHub

git clone https://github.com/Kaiser-eng/-SueldoNeto.git
cd SueldoNeto

## 2. Crea el entorno virtual

python -m venv venv

## 3. Activa el entorno virtual

##En Windows:

venv\Scripts\activate

## 4. Ejecuta el programa

python sueldo_neto.py
